# 🔗 Rusty Link Shortener

Высокопроизводительный сервис для сокращения ссылок с аналитикой переходов и кэшированием, написанный на Rust.

## 🚀 Особенности

- **Сокращение ссылок**: Генерация коротких, непредсказуемых кодов с помощью `nanoid`.
- **Редирект с аналитикой**: Переадресация (HTTP 303) с одновременной записью лога перехода (IP-адрес, User-Agent).
- **Статистика**: Аналитический эндпоинт с агрегацией данных (всего кликов, время последнего клика, топ-5 браузеров).
- **Кэширование (Cache-Aside)**: Интеграция с Redis для мгновенной отдачи горячих редиректов. Кэш имеет TTL (1 час).
- **Отказоустойчивость**: Паттерн Fail-Open — при недоступности Redis сервис продолжает работать, обращаясь напрямую к базе данных.
- **Миграции БД**: Версионирование схемы базы данных с помощью `sqlx::migrate!`.

## 🛠 Стек технологий

- **Язык**: Rust
- **Web-фреймворк**: Axum + Tokio (асинхронный рантайм)
- **База данных**: SQLite + SQLx (пул соединений, prepared statements)
- **Кэш**: Redis (асинхронный драйвер `redis-rs`)
- **Сериализация**: Serde / Serde JSON

## 📡 API Эндпоинты

### 1. Создать короткую ссылку
`POST /shorten`

**Тело запроса:**
~~~json
{
  "url": "https://rust-lang.org"
}
~~~

**Ответ (201 Created):**
~~~json
{
  "code": "jSEaFYL",
  "short_url": "http://localhost:3000/jSEaFYL",
  "original_url": "https://rust-lang.org"
}
~~~

### 2. Редирект
`GET /{code}`

Возвращает `303 See Other` и заголовок `Location` с оригинальным URL. В фоне записывает клик в базу (для аналитики) и кэширует URL в Redis.

### 3. Получить статистику
`GET /stats/{code}`

**Ответ (200 OK):**
~~~json
{
  "code": "jSEaFYL",
  "url": "https://rust-lang.org",
  "total_clicks": 6,
  "last_click": "2026-10-23 16:50:27",
  "top_user_agents": [
    {
      "user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ... Chrome/149.0.0.0 Safari/537.36",
      "clicks": 4
    },
    {
      "user_agent": "curl/8.0.1",
      "clicks": 2
    }
  ]
}
~~~

## 🏗 Архитектура и База данных

Проект использует две таблицы SQLite (управляются через миграции):
- `links`: хранит короткие коды (`code` PK) и оригинальные URL-адреса.
- `clicks`: лог переходов. Связана с `links` внешним ключом (`FOREIGN KEY ... ON DELETE CASCADE`).

**Схема кэширования (Cache-Aside):**
1. При запросе `GET /{code}` сервер сначала ищет ключ в Redis.
2. Если ключ найден (**Cache Hit**) — редирект отдается за микросекунды без обращения к диску.
3. Если ключа нет (**Cache Miss**) — сервер идет в SQLite, достает URL, сохраняет его в Redis с TTL (3600 секунд) и отдает редирект.

## 💻 Локальный запуск

1. Убедитесь, что у вас установлен Rust (`cargo`) и Redis.
2. Запустите Redis (в WSL или Linux):
   ~~~bash
   sudo service redis-server start
   # или
   redis-server --daemonize yes
   ~~~
3. Запустите сервер:
   ~~~bash
   cargo run
   ~~~
4. Сервер будет доступен по адресу `http://localhost:3000`.
